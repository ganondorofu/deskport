# Deskport

日本語 | [English](README.en.md)

スマホやタブレットから、PC の画面を低遅延で見て操作するリモートデスクトップです。
Galaxy Z Fold 8 Ultra(折りたたみ)に合わせて作り始めましたが、特定の端末には限りません。

## 特長

- **自作の配信:** 画面取得(DXGI)、GPU による HEVC 符号化(NVENC)、UDP で送ります。60fps 以上に対応します。
- **暗号化:** 映像、音声、カーソル、操作のすべてのパケットを、AES-256-GCM で暗号化します。
- **複数ディスプレイ:** 1 枚だけを見ることも、全部を並べて見ることもできます。ディスプレイの解像度は、自動で合わせます。
- **QR で登録:** PC に出る QR を、スマホで読み取るだけです。鍵の入力は要りません。
- **LAN でも VPN でも:** 1 台の PC に複数のアドレスを登録でき、つなぐときに、最も速いものを自動で選びます。VPN の種類は問いません。
- **音声:** PC で鳴っている音を、スマホで鳴らします。PC の音量や設定は変えません。音量はスマホ側で調整します。
- **ファイル転送とクリップボード:** スマホと PC の間で、ファイルを送り合い、文字列のクリップボードを同期します。PC 側の置き場所は `ダウンロード\Deskport` です。
- **操作:** タッチ、トラックパッド、スクロールホイール、キーボード(コンパクト、テンキーなし、フルサイズ。US/JIS)、ショートカットの自作、修飾キーの固定(Alt+Tab など)、長押しドラッグ、カーソルの追従と慣性。
- **統合キーボード:** キーボードの上で、そのまま、トラックパッドとして使えます(スワイプでカーソル、2 本指でスクロール)。
- **折りたたみ対応:** 姿勢(ストレート、フレックス、展開)ごとに、配置と設定を別々に覚えます(折りたたみでない端末では、オフにできます)。
- **接続時のパスワード:** スマホのアプリを開いた人が、勝手に PC へつなげないように、4 桁の数字か、自由な文字列で守れます(パスワードマネージャーの自動入力に対応)。
- **カメラ(Windows 11):** スマホのカメラを、PC のカメラとして、Teams、Zoom、ブラウザなどで使えます。
- **ロック画面と UAC(任意):** ロック画面、UAC の確認画面、Ctrl+Alt+Del も操作できます。
- **言語:** 日本語と English(端末の言語に従います。設定の「その他」で変えられます)。
- **自動更新:** 署名つきの更新情報を確かめて、PC もアプリも更新できます。

## 動作環境

| | |
|---|---|
| ホスト(PC) | Windows 10/11、NVIDIA GPU(NVENC)、WebView2(Windows 11 には入っています)。カメラは、Windows 11(ビルド 22000 以降)だけ |
| 端末 | Android 14 以降 |

NVIDIA 以外の GPU には、まだ対応していません。

## 使い方

1. [Releases](https://github.com/ganondorofu/deskport/releases) から、`deskport-host.exe` と `deskport.apk` を取ります。
2. PC で `deskport-host.exe` を開き、「インストール」を押します(管理者権限の確認が 1 回出ます。ファイアウォールの設定のためです)。
3. スマホに `deskport.apk` を入れます。
4. アプリのホスト画面で「QRで登録」を押し、PC の窓の「登録」タブの QR を読み取ります。
5. 登録したホストをタップすると、つながります。

QR には鍵が入っています。他の人に見せないでください。鍵は「登録」タブから作り直せます(登録済みの端末は、使えなくなります)。

### カメラ(スマホのカメラを PC のカメラにする)

1. PC の窓の「設定」→「カメラ」→「有効にする」(確認のあと、管理者権限の確認が 1 回出ます)。
2. Teams などのカメラの選択肢に、「Deskport Camera」が出ます。映像がないときは、灰色の画面です。
3. スマホで PC につないで、右上の「⋮」→「カメラを PC に送る」。映像が、PC のカメラに映ります(15fps 前後、約 1280x720)。

- カメラを有効にしている間、ホストが動いている限り、仮想カメラは Windows に出ています。「無効にする」か、ホストを終えると、消えます。
- スマホのアプリが画面に出ている間だけ送れます(バックグラウンドでは、Android がカメラを止めます)。
- 仮想カメラの DLL を、`C:\Program Files\DeskportVCam` に置いて、登録します(HKLM)。無効にすると、登録を消します。

### ロック画面と UAC(任意)

PC の窓の「設定」→「ロック画面・UAC への対応」→「有効にする」(確認のあと、管理者権限の確認が 1 回出ます)。スマホ側の設定は要りません。有効にすると、スマホは、補助プロセス(UDP 49001)につなぎます。

- Windows のサービス(SYSTEM 権限)を 1 つ入れます。**有効にしている間は、この PC で動く他のプログラムも、鍵(`secret.txt`)を読んで、UAC の確認などを操作できてしまいます。** 使わないときは、「無効にする」を押してください(サービス、ファイル、ファイアウォールの規則を、すべて消します。Windows のポリシーは変えません)。
- つないでいるときは、右上の「⋮」に「Ctrl+Alt+Del を送る」が出ます。
- この接続のあいだも、ファイル転送は、通常の接続(TCP 49000)を使います。ロック中は使えません。
- ホストを更新したときは、サービスの実行ファイルは古いままです。「無効にする」→「有効にする」で入れ直してください。

## 知っておくこと

- **ファイアウォール:** インストール時に、UDP 49000(映像と操作)と TCP 49000(ファイル転送とクリップボード)の受信を許可する規則を、すべてのプロファイル(プライベート、パブリックなど)で作ります。ロック画面・UAC への対応を有効にすると、UDP 49001 の規則も足されます。信頼できないネットワークでも開くので、鍵を他人に渡さないでください。
- **IPv6:** IPv4 だけに対応しています。
- **マイク:** スマホのマイクを PC に送る機能は、ありません。PC のマイクとして割り込ませるには、仮想マイクのドライバー(署名つき)が要るためです。代わりに、スマホのキーボードの音声入力で、文字として送れます。
- **時計:** 接続要求は、PC と端末の時刻が 60 秒以内のときだけ通ります。ずれていると、PC のログに秒数が出ます。
- **更新の確認:** ホストは、起動の少しあとと 6 時間ごとに、GitHub の `releases/latest` へ更新情報を取りに行きます。送るのは、通常の HTTPS の要求だけです。止めるには、`%APPDATA%\Deskport` に、空の `no-update-check` というファイルを作ります。
- **同時接続:** 最大 8 配信までです。
- **カメラの診断ログ:** `C:\ProgramData\DeskportVCam\log.on` というファイルがあるときだけ、`vcam.log` に書きます。

## ビルド

必要なもの: Rust、Android Studio(JBR と SDK)。

```powershell
# 取得
git clone https://github.com/ganondorofu/deskport.git
cd deskport

# 仮想カメラの DLL(先にビルドします。ホストに埋め込むため)
cd vcam
cargo build --release          # vcam\target\release\deskport_vcam.dll

# ホスト
cd ..\host
cargo build --release          # host\target\release\deskport-host.exe

# アプリ
cd ..
.\gradlew.bat assembleDebug    # app\build\outputs\apk\debug\app-debug.apk
```

リリース(署名と、GitHub Releases への公開)は `scripts\release.ps1` です(仮想カメラのビルドも含みます)。署名鍵は、リポジトリの外(隣の `deskport-keys`、または環境変数 `DESKPORT_KEYS` のフォルダ)に置きます。

## 構成

| 場所 | 内容 |
|---|---|
| `app/` | Android アプリ(Kotlin、Jetpack Compose) |
| `host/` | PC のホスト(Rust、Tauri)。配信、入力、音声、トレイ、窓、インストール、更新、ロック画面・UAC 対応のサービス、カメラの受信 |
| `vcam/` | 仮想カメラ(Rust。Windows 11 の Media Foundation 仮想カメラのメディアソース。`vcam-tool` は、試験用) |

通信の形式は `host/src/serve.rs` と `host/src/crypto.rs` の冒頭にあります。
